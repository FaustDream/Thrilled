# Thrilled

新标签页扩展，极简冷调设计。

## 当前状态（v4.4）

- `v4.1` 起：**v4 功能重构完成**——React 18 + Vite + TypeScript，按「`app` 视图层 / `core` 服务层 / `background` / `shared`」分层；界面按 UiTab 实测基准复刻（`uetab.com`，见 04 文档），形态为「固定 1920 设计稿坐标系 + 60px 单元格绝对定位网格 + 横向翻页 + 风格皮肤系统 + 内容完全自定义」。
- **内容模型**：卡片 = 对小组件定义的一次引用 `{ id, c, r, w, h, t, config }`——位置与尺寸属于布局，`config` 属于内容；添加 / 删除 / 改尺寸 / 换类型 / 改内容 / 拖动 / 整套布局导入导出全部可用。见 [02-UI规格.md](docs/v4/02-UI规格.md) §13。
- **本地持久化（4.1 新增）**：设置 / 布局 / 引擎 / 皮肤 / 搜索历史整存整取到 `chrome.storage.local`（浏览器开发预览回退 localStorage），改动防抖落盘；支持 v3 数据一次性迁移（磁贴 → 网址图标、引擎顺序、搜索历史、昵称等）。
- **搜索引擎**：内置 12 个主流引擎（百度 / 必应 / 谷歌 / 搜狗 / 360 / 神马 / 夸克 / 头条 / 知乎 / 微博 / DuckDuckGo / Brave）+ 自定义；搜索框左侧图标即下拉入口，支持隐藏、拖拽排序。
- **风格皮肤**：内置经典 / 光感 / 暗黑 / 黑紫 / 晨曦 / 黛青六套仅为**出厂初始值**，12 项取色编辑器可自定义配色、改名、新建、删除、还原。**界面风格不做任何颜色限制。**
- **视觉体系（v4.4）**：纯净浅灰蓝默认背景，搜索框为唯一强焦点；网址图标无卡片化（品牌字形直落背景）；小组件卡统一 16px 圆角 + 单一轻投影；Dock 玻璃磨砂悬浮栏（苹果式尺寸，快捷方式显站点 favicon、功能键显单色线性图标）；模式胶囊收起只显当前模式图标、悬停展开「极简 / 标准」两选项（无说明文字）；弹簧动效、卡片入场渐次浮现、弹窗缩放入场。
- **壁纸（v4.4）**：系统不内置任何壁纸资源；「我的壁纸」支持本地上传（图片压缩 1920px / 最大 5MB）、外链上传与视频壁纸（mp4 / webm）；「壁纸来源」统一适配器架构接入多个外部壁纸网站——Wallhaven / Picsum / 必应每日 / 061129 精选 / 哲风五种协议适配器（同构 API 可改基址接镜像）；「壁纸」面板合并为一张卡片：顶部缩略图 + 名称与体积一行，下方来源列表单行承载——**点行名预览该源**（当前项标「预览中」）、开关控制启用禁用、行尾「···」改地址或移除，列表末尾文字入口「+ 添加来源」补入尚未添加的来源；支持关键词搜索（Wallhaven 服务端搜索、061129 客户端关键词过滤，由适配器声明提供），按来源原有分类浏览（Wallhaven 的 General/Anime/People、061129 的插画/动漫/风景…原站结构），点击即下载原图落地 IndexedDB（20MB 上限）并设为壁纸（图片经 `<img>` 全窗口铺满渲染，不走 CSS 变量，避免超长 dataURL 触发浏览器声明长度上限）；等待期间网格上覆盖应用任务浮层，按「正在下载壁纸（字节进度）/ 正在处理图片 / 即将应用」三段反馈，含进度条、循环等待环与步骤条，总量不可知时自动转为循环扫光；请求经 SW 后台代理绕过跨域，开发预览回退直连。**自适应**：图片经 `object-fit:cover` 等比填满（不变形、无黑边），裁剪位置不再固定居中——按视口宽高比自动挑主体最集中的窗口（降采样灰度 + Sobel 边缘能量 + 中心先验 + 明度方差滑窗评分）写入 `object-position`，竖屏 / 改窗口 / 换屏时自动重算。**去重与历史**：IndexedDB 主键改为源地址哈希（本地上传用图片内容哈希），同一张图命中即跳过整段下载；「壁纸」面板带横向历史缩略图带，保留最近 12 张，点缩略图直接切换。来源可用性均经 HTTP 状态码实测验证；哲风壁纸在用户明确授权的例外下接入（按站方公开前端使用的传输协议实现，原图下载需登录站方账号，故以站方裁剪图为图源）。
- **透明度与毛玻璃（v4.4）**：两组**独立**设置，互不影响。透明度 12 项——玻璃底色 6 项（卡片 / 图标容器 / Dock 快捷栏 / 搜索框 / 面板与弹窗 / 菜单与浮层，保留可读下限）与元素显隐 6 项（图标图形 / Dock 图标 / 时间与日期 / 每日一言 / 边框与分隔线 / 悬停与激活态，可一路调到消失），另有全局透明度叠加。毛玻璃模糊 6 项（0–20px，与有玻璃底色的六个透明度项一一配对）：只降透明度不调模糊会「透但看不清」，两组配对才通透。每项名称右侧的 ⓘ 悬停 200ms 或点击展开作用范围说明，气泡逼近面板右缘时自动向左翻转。
- **真实数据**：天气卡接 Open-Meteo 实况（30min 缓存，定位超时降级北京）；搜索 / 卡片 / Dock / 导航点击经 `core/link-opener` 按打开方式设置真实跳转。
- **云端同步（4.3）**：设置 → 「云端同步」配置服务器地址与访问令牌（**仅保存在本机浏览器存储，绝不进入代码仓库**）；配置后本地改动自动上传，云端为唯一权威数据源，换设备填同一配置「从云端恢复」一键还原。参考服务端见 [server/README.md](server/README.md)（零依赖 Node 单文件，Token 鉴权，数据原子落盘）。
- **Dock（4.4）**：出厂快捷方式为空、由用户手动新增——「添加」抽屉自定义页签勾选「同时添加到底部 Dock」；快捷方式图标显示站点 favicon（失败回退品牌字形），右键可打开 / 修改名称 / 修改网址 / 从 Dock 移除（`settings.dockApps`，`{name,url}` 结构）；右侧固定三个功能键：新增 / 个性化 / 设置（右上头像已移除）；悬停按指针接近度苹果式放大。侧边抽屉直角样式；「添加」抽屉网址导航展示真实 favicon（失败回退品牌字形）。
- **三面板 + 云端同步（4.4）**：添加（小组件 / 网址导航分类 / 自定义+图标上传+文件夹）、个性化（无副标题单行头部；壁纸 / 背景效果 / 显示 / 搜索与Dock / 主题——主题缩略图一排 4 个 + 12 项色值 4 列密排）、设置（与个性化同一套分布方式：搜索 / 通用 / 数据 / 云端 / 关于 五个分区页签，各模块以卡片分组，说明收进标题 ⓘ，危险操作单独成卡并标红）；欢迎选风格 / 添加引擎 / 更新记录 / 关于 / 备份 / 恢复 / 一键重置弹窗齐备，重置类操作均二次确认。登录与账号体系已移除（个人使用阶段），云端存储改为配置注入式直连；在线广场（模板分享）已整体移除，个性化里的主题（风格皮肤）不受影响。
- **设置分区（4.4 改版）**：分区按使用频率 × 风险排序——**搜索**（引擎清单拖拽排序 / 启用 / 隐藏 + 添加自定义，搜索框四个行为开关）、**通用**（打开方式互斥单选 + 每日问候昵称）、**数据**（备份与迁移：备份 / 恢复默认 / 导出 / 导入布局 / 导入收藏夹 / 恢复本地快照；重置与清理：清除本地数据 / 一键重置，红色标识）、**云端**（服务器地址与令牌、上传 / 恢复）、**关于**（版本、更新记录 / 关于我们、快捷键表）。卡片内主按钮在前、低频动作退到第二行，说明文案统一收进标题右侧 ⓘ。
- **v3 能力接回**：收藏夹导入（书签树 → 网址图标）、本地目录同步（File System Access，数据写盘 / 恢复）、导出导入布局 JSON、快捷键（`←→` / `Ctrl+Shift+E` 导出 / `Ctrl+Shift+R` 重置）。

## 目录结构

```
src/
├─ app/            React 视图层（不直接碰 chrome.*）
│  ├─ main.tsx     入口（装配 platform 平台注入）
│  ├─ App.tsx      舞台装配：搜索 / 翻页网格 / Dock / 模式胶囊 / 浮层
│  ├─ store.ts     zustand：设置 · 布局 · 引擎 · 皮肤 · 持久化（hydrate/scheduleSave）
│  ├─ layout.ts    出厂布局 + 导入归一化（栅格算法在 shared/grid）
│  ├─ widgets.tsx  小组件渲染器（定义表在 shared/widget-defs）
│  ├─ panels.tsx   抽屉（添加/个性化/设置）+ 弹窗 + 皮肤编辑器
│  ├─ menus.tsx    右键菜单（全局 11 项 / 卡片 6 项）
│  ├─ brands.ts    品牌色字形 + 站点 URL 注册表
│  ├─ platform.ts  core 层 UI 回调注入（file-config 等）
│  ├─ icons.tsx    图标集
│  └─ styles/      令牌与样式（来自 docs/v4/index.html 冻结原型）
├─ core/           框架无关服务层：storage（v4 文档 + kv）/ wallpaper（IndexedDB）/
│                  file-config / favicon / export / reset / migrate（v3→v4）/
│                  weather / quotes / search 链接打开 / bookmark-importer / logger / errors / utils
├─ background/     service worker（index.ts + favicon-resolver.ts）
└─ shared/         类型 · 常量 · 默认值（皮肤/设置）· 网格算法 · 小组件定义表 · 消息协议
```

**分层铁律**：`core/` 与 `background/` 不 import React；`app/` 不直接调用 `chrome.*`，一律经 `core/`。

## 开发

```bash
pnpm install
pnpm dev         # Vite 开发服务器（浏览器直接预览界面）
pnpm typecheck   # 类型检查
pnpm test        # 单元测试（layout / guards / bookmarks）
pnpm build       # 构建扩展 → dist/（Vite 出应用，esbuild 出 background）
pnpm release     # 打包 releases/
```

加载扩展：Chrome → `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择 `dist/` 目录。
