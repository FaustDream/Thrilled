# Thrilled

新标签页扩展，极简冷调设计。

## 当前状态（v4.4）

- `v4.1` 起：**v4 功能重构完成**——React 18 + Vite + TypeScript，按「`app` 视图层 / `core` 服务层 / `background` / `shared`」分层；界面按 UiTab 实测基准复刻（`uetab.com`，见 04 文档），形态为「固定 1920 设计稿坐标系 + 60px 单元格绝对定位网格 + 横向翻页 + 风格皮肤系统 + 内容完全自定义」。
- **内容模型**：卡片 = 对小组件定义的一次引用 `{ id, c, r, w, h, t, config }`——位置与尺寸属于布局，`config` 属于内容；添加 / 删除 / 改尺寸 / 换类型 / 改内容 / 拖动 / 整套布局导入导出全部可用。见 [02-UI规格.md](docs/v4/02-UI规格.md) §13。
- **组件库与三层分工（4.4 起）**：**组件库**（个性化 → 第 4 个页签）管「放什么」——**9 类组件**按**组件类型**分组浏览（**时间** = 时钟 / 日历 / 倒计时、**信息** = 天气 / 待办、**图标** = 网站图标 / 图标文件夹 / 收藏夹 / 图标格容器；新闻热点、翻译、计算器、AI 对话与「内容」分组已整体下架），顶部另有出厂固定的高频组**「常用」**（时钟 / 天气 / 待办 / 网站图标，置顶快捷入口）；已添加显示灰态、一键添加；页面上已放置的组件在此可**拖拽排序**（只改列表顺序，位置仍在页面上拖动）与「··· → 配置 / 移除」，空页给出「页面暂无组件，从下面挑一个」。**库内不显示尺寸**：设置集中在页签底部的**「组件默认大小」**卡片——点「设置」打开弹窗，按分组逐个类型选档（含「出厂」一档），点「确认设置」才生效（选档 / 取消不改设置），只影响之后新增的该类型实例（批量导入的网址图标同样遵循）；单个实例的尺寸走页面右键菜单「修改尺寸」或 ··· →「配置」（六档）。**个性化**管「长什么样」，**设置**管「怎么运作」。每个组件的配置 ≤5 项，分**通用**（名称留空回退组件名 / 透明度跟随全局或单独覆盖）、**样式**（字号缩放 / 图标缩放 / 卡片圆角 / 文字颜色，四项对所有组件生效且按实例保存）与**专属**（每个组件 1–3 项：日历的显示年月与农历、天气的温度单位与区间、倒计时的计时模式 / 下班时刻 / 目标日期、文件夹的显示名称…；倒计时的「显示节日倒数 / 吉祥物图形 / 纪念日标题 / 天数单位」在倒计时详情弹窗里管理）；字段类型对齐 Storybook `argTypes.control` 词汇（text / num / list / bool / sel / **range** / **color**），后续组件加配置只需在定义表声明。**样式复用**：一键预设（紧凑 / 标准 / 宽松）、「设为该组件默认」（新放置的实例自动套用该类默认样式）、「复制到同类卡片」（同页同类型一次刷齐），**类型级默认值**（默认样式 + 默认大小）随文档持久化并在设置归一化里做白名单与限幅（默认大小另需落在该组件的尺寸能力区间内）。Dock 快捷栏开关在「背景效果」页签的「搜索与 Dock」卡。
- **本地持久化（4.1 新增）**：设置 / 布局 / 引擎 / 皮肤 / 搜索历史整存整取到 `chrome.storage.local`（浏览器开发预览回退 localStorage），改动防抖落盘；支持 v3 数据一次性迁移（磁贴 → 网址图标、引擎顺序、搜索历史等）。**纯本地运行**：不含任何云端同步 / 上传通道，数据只在本机（4.4 起移除云端同步与参考服务端）。**旧类型转接**：「倒数日」「纪念日」已并入倒计时，存量卡片在载入与旧备份导入时自动转成对应计时模式（位置 / 尺寸 / 配置原样保留）。
- **搜索引擎**：内置 12 个主流引擎（百度 / 必应 / 谷歌 / 搜狗 / 360 / 神马 / 夸克 / 头条 / 知乎 / 微博 / DuckDuckGo / Brave）+ 自定义；搜索框左侧图标即下拉入口，支持隐藏、拖拽排序。
- **风格皮肤**：内置经典 / 光感 / 暗黑 / 黑紫 / 晨曦 / 黛青六套仅为**出厂初始值**，12 项取色编辑器可自定义配色、改名、新建、删除、还原。**界面风格不做任何颜色限制。**
- **视觉体系（v4.4）**：纯净浅灰蓝默认背景，搜索框为唯一强焦点；单个网址图标无卡片化（品牌字形直落背景，图标类卡片四边内缩 **14px**、小组件 25px：2×2 图标卡 120×120、相邻间距 28px、卡内字形 84px——比早期的 98/50/60 紧凑一档），**图标格容器内的图标保留标准方块容器**（行列按卡片尺寸自动铺满，见 shared/grid 的 `groupGrid`；格子多到装不下时容器转为可滚动，格子保持可辨识尺寸）；名称标签不再常显（4.4 补丁 14：界面不显示组件名）；**网站的辨认**改由悬停提示承担（见下条「图标识别」）；卡片区 1776px（24 列 × 74px）居中于 1920 设计稿，搜索框底缘与首行卡片之间留 24px；小组件卡统一 16px 圆角 + 单一轻投影；Dock 玻璃磨砂悬浮栏（苹果式尺寸，快捷方式显站点 favicon、功能键显单色线性图标）；模式胶囊收起只显当前模式图标、悬停展开「极简 / 标准」两选项（无说明文字）；弹簧动效、卡片入场渐次浮现、弹窗缩放入场。
- **自动整理 · 跨页（v4.4 补丁 33 / 34）**：删除网格上的**图标类卡片**（网站图标 / 图标文件夹 / 图标格容器）后自动补位——按「页序 + 页内自上而下、自左而右」依次落到**全局最靠前**的空位，**前面的页一留白就由后面页的图标补齐，空洞被推到最后一页末尾**（页被搬空则自动移除）；相对顺序不变、**组件（时钟 / 天气 / 待办等）钉在各自页原位**、尺寸对不上时链条自然停止。判定空位时其它卡片全部算障碍（已处理的用新位置、未处理的用原位），因此每张卡片只会往前补空、绝不会乱跳。设置 → 通用 →「页面整理」的「删除后自动整理」**默认开**（删除组件不触发）；手动入口 = 空白处右键「整理图标」（常驻，提示「已整理 N 个图标 / 没有需要移动的图标」）。卡片位置变化带 260ms 平移动画（拖拽中不受影响）。
- **拖拽落位（v4.4 补丁 34）**：拖到哪儿都能放下——目标格空着直接落；被**一张同尺寸**卡片占着则**两张互换位置**；压到多张或尺寸装不下则**就近落位**（提示「目标位置被占用，已就近放置」）；确无空位才提示「这里放不下，换个位置试试」。手动拖动不会触发自动整理。
- **拖拽由长按触发（v4.4 补丁 35）**：进入拖拽的唯一入口是**按住不动 0.5 秒**——单击绝不会让卡片动起来（原先「按下后位移超 4px 就进入拖拽」，4px 是屏幕像素，点击时的手抖 / 触控板轻滑就能越线，观感就是「点一下卡片就进入移动状态」）。长按到点时卡片「拿起来」：放大 1.06 + 强调色光圈 + 投影加深 + 网格对齐线强制出现 + `navigator.vibrate` 触觉（能震就震），松手即恢复普通态；**原地松手不打开卡片**。按住期间指针漂移超过 12px 视为「想拖但没按住」：本次按下作废（既不拖、也不开卡片）并给一次提示「拖动卡片需先长按 0.5 秒：按住不动再拖」（一次会话只提示一次）。触摸设备上卡片加 `touch-action:none` 接住自己的手势，并补 `pointercancel` 收尾（中断即回原位，不落位也不打开）；favicon 关掉原生图片拖拽（否则会抢走指针）。单击打开、右键菜单、悬浮 ✎ / 🗑、Esc 取消、对齐吸附与落位规则全部不变。参数 `HOLD_MS = 500` / `HOLD_SLOP = 12`，不做设置项。
- **跨页拖拽与多选搬页（v4.4 补丁 36）**：图标能拖到别的页——**拖到舞台左右边缘停留 0.6 秒自动翻页**（`PAGE_EDGE_PX = 110` / `PAGE_EDGE_MS = 600`；翻过后仍停在边缘可继续翻下一页，离开边缘带 / 松手 / Esc 立即取消），拖拽中**滚轮与方向键翻页**也可用（翻页后按最后指针位置重算落点，不依赖新的 pointermove）。拖拽中的卡片改由**舞台级浮层**渲染（源页不再渲染它——它原本渲染在自己那页的 `.grid` 里，`#pager` 一平移就被带走），几何用 `GRID_LEFT / GRID_TOP + 舞台缩放`**静态换算**（翻页有 420ms 过渡，读实时 rect 会拿到滑动中的坐标）；跨页时预览与落位共用 `layout.crossPlan`。**多选**：`Ctrl/Cmd 单击`切换、`Shift 单击`取「锚点到这张之间**同类型**」的卡片（收紧为同类型，否则按 (r,c) 划一段会把路径上的图标格容器一起选中），选中给强调色描边；长按已选中的卡片 = 搬整组（主卡跟手 + 数量角标 + 目标页虚线落点格），长按未选中的 = 清空选择只拖这张；点空白 / 单击卡片 / Esc 清空（Esc 两级：先取消拖拽、再清选择）。**落位规则**：跨页**不做互换**；单张就近落位，多张按「源页页序 + 页内 (r,c)」依次填空位（与「整理图标」同一口径，绝不重叠）；**能放几张放几张**、其余留在原页并在提示里说明；目标页满时明确提示「放不下」，既不静默失败也不偷偷新建页。搬完按「删除后自动整理」设置整理**各源页**（`layout.packPage` 单页整理——不能改用跨页的 `arrangePages`，那会把刚落下的卡片又挪走），源页被搬空则连空页一起移除。另给不用拖的入口：图标类卡片右键 →「移动到」→ 第 N 页（右键的那张在多选集合里就搬整组）。批量是桌面语义（Ctrl / Shift 与右键在触摸端都不可达）。
- **拖拽跟手 / 帧率 / 缓动（v4.4 补丁 37）**：拖拽中的卡片**自由跟随指针**（`transform: translate3d()` 定位，不触发布局，加 `will-change: transform`），只有某一轴吸住对齐候选时那一轴才"咬"到候选格上（约 120ms 弹簧）——**自由跟手时过渡必须是 0**，否则是拖影不是跟手。「会落在哪」改由**虚线占位格**表达（页内单张＝候选格；跨页 / 多选＝`crossPlan`，与松手后的落位**同一个函数**）。帧率三件事：`pointermove` 只登记坐标、**合并到 rAF** 算一次（实测 150 个事件 = 1 次更新）；舞台 rect 带缓存（只在窗口尺寸变化与每次按下时失效），每帧的 `getBoundingClientRect` 从 2 次降到 0；`GridCard` 与 `Drawer` 加 `memo`、卡片按下改由全页共用一个引用稳定的处理器（内联箭头会让 memo 每帧失效）→ 拖拽中真正重渲染的只剩浮层那一张。缓动：松手**飞回落位**（FLIP：先写平移偏移、下一帧去掉，交给 `.item` 自带的 transform 过渡）、刚拖完的卡片跳过入场动画（否则先消失再淡入）、「拿起来」对浮层卡真正生效、拖拽中翻页 0.42s → 0.24s；拖拽时给 `#stage` 打 `data-drag="1"` 关掉底层卡片的 hover 动效（横扫一排图标不再逐张上浮 / 放大）。长按进入拖拽、单击打开、跨页、多选、Esc、落位规则全部不变。
- **右键菜单（v4.4 补丁 25–28 / 33）**：**空白处**右键 = 8 项固定菜单（**添加网站图标 / 添加网站容器** / 添加到 Dock 快捷方式 / 添加组件（二级列 9 类，**已在页面上的单例型组件置灰并标「已添加」**，图标类可重复添加）/ 打开添加面板 / 打开个性化 / 打开设置 / 整理图标）——前两项**一步生成**、不弹表单（新卡片会播一次高亮指明落位，编辑走卡片悬浮 ✎ 或右键「编辑信息」），「添加网站图标」固定在**第一级第一项**；「添加到 Dock 快捷方式」走弹窗（只填网址，不写 `https://` 也会自动补全；落点可选 Dock / 页面图标 / 两者都加）；新建的图标**落在右键所在的格**（被占则就近）；**卡片**右键 6 项（打开 / 编辑信息 / 更换小组件 / 修改尺寸 / 添加到文件夹 / 删除该书签）；**Dock 图标**右键 5 项（打开 / 修改名称 / 修改网址 / 从 Dock 移除 / 配置快捷方式…）。输入框、抽屉、弹窗与引擎面板内部的右键仍是浏览器原生菜单。
- **添加结果可见（v4.4 补丁 28 / 30）**：右键一级、添加抽屉（网址导航点站点 / 自定义确认 / 书签快速添加）与组件库三处「添加网站图标 / 图标格容器」都是**一步生成、不弹任何表单**（编辑走后续操作：卡片悬浮 ✎ 或右键「编辑信息」）；单次添加后**自动收起抽屉**让新卡片直接露出来，并播一次 1.9s 高亮（强调色描边 + 光晕 + 临时浅底，去卡片化的图标也因此看得清）；批量导入不收起抽屉。
- **对齐辅助（v4.4 补丁 29）**：拖拽卡片时**网格与组件对齐统一吸附**——以最近网格格为基准（卡片始终落在格上），若与同页**邻近**卡片的边缘或中心偏差不超过 0.3 格（22px）则优先吸附到对齐位置；拖动中卡片**实时落在候选格上**并保留抓取偏移，吸附到组件时显示**贯穿整页的参考线**并高亮目标卡片，按 Esc 可取消拖拽。设置 → 通用 →「对齐辅助」可分别开关「组件吸附」「显示对齐参考线」「显示网格对齐线」。
- **图标识别（v4.4 补丁 32）**：图标卡与图标格容器里的格子只有品牌字形，字形相似或重复时认不出是哪个网站——**悬停提示**覆盖四处（网格图标卡 / 图标格容器里的每个格子 / 图标文件夹卡 / Dock 图标），在元素上方（放不下则翻到下方、两端钳制）浮出气泡：第一行站点名称、第二行域名（容器格子只有名称）；**延迟 250ms** 出现（横扫一排图标不闪一片）、移出 100ms 淡出，固定深色底 + 白字（不随皮肤，明暗壁纸都清晰），140ms 淡入 + 4px 位移（翻转时方向相反）。气泡画在舞台顶层——卡片与容器都是 `overflow:hidden`，挂在元素内部会被裁掉；Dock 图标原有的浏览器 `title` 也换成同一套气泡。**常显名称（可选，出厂关）**：设置 → 通用 → 「图标显示名称」开启后在图标卡的字形下方常显站点名（名字落在卡片下沿之外，因为 98px 的卡内底部一行要么给名字要么给悬浮按钮，实测会重叠一半），纯文字 + 双层描边（线芯取「名称标签」令牌 = 设置里的字体颜色，描边按皮肤明暗派生），长名称单行省略号、全名仍在悬停气泡里；容器格子与 Dock 不常显（格子 64px 上限、Dock 栏高 60px），容器卡自身不加提示。
- **组件尺寸自适应（4.4 补丁 12）**：卡片自身就是 CSS **查询容器**（`container-type:size`），组件排版用容器查询单位表达——`--u = max(1px, min(100cqw / 自然宽, 100cqh / 自然高)) × 字号缩放` 即「1 设计像素」。**自然尺寸下 --u = 1px**（渲染与设计稿逐像素一致），比自然尺寸大的卡片按短边比**等比放大**（字体、图标、图标格容器、圆角、内外间距全部跟随；实测图标卡 2×2 → 4×4 时图标 60 → 151px），更小的卡片保持设计字号不缩小（出厂布局本就把时钟放在 4×2 等小档位）。细则：**尺寸能力**——每类组件声明最小 / 最大档位（`WidgetDefinition.min/max`，仿 react-grid-layout 的 minW/minH），组件库三档、配置弹窗六档与右键「修改尺寸」都据此置灰或过滤，store 兜底拦截（倒计时 / 日历 / 天气 / 时钟 / 图标格容器 4×2 起，倒计时 4×4 档含倒数列表），并**按实例内容再收紧**——图标格容器按应用数与标签条带算出「该档能否不滚动装下」，装不下的档位直接置灰；**宽卡扩展**——卡片宽度 ≥ 420px 时天气卡多显示一行「明日温度」、倒计时（倒数日 / 纪念日模式）多显示日期行（窄卡自动隐去，出厂尺寸外观不变）；**密度降级**——窄卡按 @container 查询减信息而非压字号（< 420px 隐倒计时熊猫）。**网格对齐线**（4.4 补丁 21 / 28）：设置 → 通用 →「组件对齐」开关（拖拽 / 添加组件时强制显示）；按 24×10 网格铺满**整个舞台**（图案对齐卡片网格原点，层级在壁纸之上、卡片与控件之下，且不拦截点击），细线 = 单元格、粗线 = 偶数格即合法尺寸边界，另叠一层浅色高光使明暗壁纸上都看得见（细线 = 单元格、粗线 = 偶数格即合法尺寸边界），拖拽组件时强制显示用于确认落位。
- **壁纸（v4.4）**：系统不内置任何壁纸资源；「我的壁纸」支持本地上传（图片压缩 1920px / 最大 5MB）、外链上传与视频壁纸（mp4 / webm）；「壁纸来源」统一适配器架构接入多个外部壁纸网站——Wallhaven / Picsum / 必应每日 / 061129 精选 / 哲风五种协议适配器（同构 API 可改基址接镜像）；「壁纸」面板合并为一张卡片：顶部缩略图 + 名称与体积一行，下方来源列表单行承载——**点行名预览该源**（当前项标「预览中」）、开关控制启用禁用、行尾「···」改地址或移除，列表末尾文字入口「+ 添加来源」补入尚未添加的来源；支持关键词搜索（Wallhaven 服务端搜索、061129 客户端关键词过滤，由适配器声明提供），按来源原有分类浏览（Wallhaven 的 General/Anime/People、061129 的插画/动漫/风景…原站结构），点击即下载原图落地 IndexedDB（20MB 上限）并设为壁纸（图片经 `<img>` 全窗口铺满渲染，不走 CSS 变量，避免超长 dataURL 触发浏览器声明长度上限）；等待期间网格上覆盖应用任务浮层，按「正在下载壁纸（字节进度）/ 正在处理图片 / 即将应用」三段反馈，含进度条、循环等待环与步骤条，总量不可知时自动转为循环扫光；请求经 SW 后台代理绕过跨域，开发预览回退直连。**自适应**：图片经 `object-fit:cover` 等比填满（不变形、无黑边），裁剪位置不再固定居中——按视口宽高比自动挑主体最集中的窗口（降采样灰度 + Sobel 边缘能量 + 中心先验 + 明度方差滑窗评分）写入 `object-position`，竖屏 / 改窗口 / 换屏时自动重算。**去重与历史**：IndexedDB 主键改为源地址哈希（本地上传用图片内容哈希），同一张图命中即跳过整段下载；「壁纸」面板带横向历史缩略图带，保留最近 12 张，点缩略图直接切换；标题行右侧「清空历史」一键清理全部历史记录（当前使用中的那张保留，二次确认后连本机图片一起删除）。**缓存**：壁纸本体下载后落地 IndexedDB（打开新标签页从本地读取，不走网络）；来源列表（分类 / 页码 / 搜索）加 30 分钟会话缓存，面板反复开关不重复请求。来源可用性均经 HTTP 状态码实测验证；哲风壁纸在用户明确授权的例外下接入（按站方公开前端使用的传输协议实现，原图下载需登录站方账号，故以站方裁剪图为图源）。
- **透明度与毛玻璃（v4.4）**：两组**独立**设置，互不影响。透明度 11 项——玻璃底色 6 项（卡片 / 图标容器 / Dock 快捷栏 / 搜索框 / 面板与弹窗 / 菜单与浮层，保留可读下限）与元素显隐 5 项（图标图形 / Dock 图标 / 时间与日期 / 边框与分隔线 / 悬停与激活态，可一路调到消失），另有全局透明度叠加。毛玻璃模糊 6 项（0–20px，与有玻璃底色的六个透明度项一一配对）：只降透明度不调模糊会「透但看不清」，两组配对才通透。每项名称右侧的 ⓘ 悬停 200ms 或点击展开作用范围说明，气泡逼近面板右缘时自动向左翻转。
- **真实数据**：天气卡接 Open-Meteo 实况（30min 缓存，定位超时降级北京）；搜索 / 卡片 / Dock / 导航点击经 `core/link-opener` 按打开方式设置真实跳转。**卡片点击直达详情（4.4 补丁 13）**：图标卡点击开站，其余各类小组件点击打开「详情」弹窗展示核心内容——天气（实况 + 三日预报 + 刷新）、时钟（实时走字 + 12/24 小时 / 秒数 / 日期快捷开关）、日历（当月月历网格、今日高亮）、待办（可勾选 / 添加 / 删除的真实清单，存卡片 config.items）、收藏夹（浏览浏览器书签、按打开方式跳转）、倒计时（下班实时倒计时 / 倒数日大字天数 / 纪念日已过去天数与下次周年）、图标格容器应用清单（点击开站）；日历详情里的农历与宜忌如实注明占位；弹窗底部「编辑配置」与编辑互通。**待办清单条目直接外显在卡上**（勾选框可点，超出的显示剩余条数）；**倒计时内置节日倒数列表**（元旦 / 春节 / 清明 / 劳动节 / 端午 / 中秋 / 国庆自动取下一次发生 + 自定义倒数日，按剩余天数排序、带进度条；熊猫吉祥物可换 emoji 或隐藏）；**倒计时 / 倒数日 / 纪念日已合并为一个控件**（三种计时模式；4×2 矮卡只留主读数；存量卡片载入时自动转换，位置与配置不变）；**收藏夹详情为 4 列图标瓦片网格 + 名称 / 网址过滤**；所有卡片**长按 0.5 秒**才进入拖拽，点按绝不触发位置变动（见「拖拽由长按触发」）。
- **自动对比（v4.4 补丁 38）**：每张卡片都会看**自己背后那块壁纸**的亮度——壁纸降采样成小灰度图（复用 `wallpaper-focus.sampleLuma`），按与 `object-fit:cover` + `object-position` **同一条公式**算出可见窗口，再把卡片矩形映射进去取局部平均与最坏亮度（不是按「上中下三带」：同一带里白云 L≈0.9、深色人物 L≈0.1，按带取平均对两者都是错的）。然后按侵入性从小到大出手：①**翻墨色**（浅底用深墨、深底用皮肤原色）②**光晕**（字形外圈反向描边 + 一点下沉投影，方向跟随背景明暗，所以品牌图标这种「翻不了色」的同样受益）③**护罩**（字形背后一圈径向渐变的软底衬，解到刚好跨过 WCAG 非文本门槛 3.2:1；壁纸够暗时是 0）④**壁纸遮罩**加成（按可见区域亮度极差，均匀壁纸不加）。卡片文字不翻墨色，改按皮肤墨色算描边强度。设置 → 个性化 → 壁纸与文字 →「自动对比」（默认开）。判定是纯函数 `shared/luma`（`pickInk` / `fixForInk` / `coverFix`），取样在 `core/walltone`；护罩 / 描边 / 投影都按设计像素写，随舞台等比缩放。
- **Dock（4.4）**：出厂快捷方式为空、由用户手动新增——「添加」抽屉自定义页签勾选「同时添加到底部 Dock」；快捷方式图标显示站点 favicon（失败回退品牌字形），右键可打开 / 修改名称 / 修改网址 / 从 Dock 移除（`settings.dockApps`，`{name,url}` 结构）；右侧固定三个功能键：新增 / 个性化 / 设置（右上头像已移除）；悬停为**排他式动效**——同一时刻只有指针下的那一个图标在动（弹性放大 + 上浮 + 主题色光晕，进入回弹 / 离开平滑归位，强度随「悬停与激活态」透明度联动），其余图标保持静止。侧边抽屉直角样式；「添加」抽屉网址导航展示真实 favicon（失败回退品牌字形）。**从书签快速添加（4.4 补丁 13）**：网址导航页签在预设分类后追加「书签」分类（读 chrome.bookmarks，条目带真实网址，分类尾部「全部导入」复用 placeMany 通道，为批量导入预留扩展位）；自定义页签新增「从书签快速添加」——展开书签列表（可按名称过滤）逐条点击即添加为主界面网址图标快捷方式。
- **右键菜单（4.4 补丁 24）**：只保留两套——**卡片右键** 6 项（打开 / 编辑信息 / 更换小组件 / 修改尺寸 / 添加到文件夹 / 删除该书签）与 **Dock 图标右键** 5 项（打开 / 修改名称 / 修改网址 / 从 Dock 移除 / 配置快捷方式…）。空白处的**全局菜单已整体移除**（原 12 项：网址导航 / 打开方式 / 搜索栏 / Dock栏 / 极简模式 / 隐藏项目 / 搜索引擎 / Dock 快捷栏 / 网格对齐线 / 站内消息 / 更新记录），右键不再拦截，交还浏览器原生菜单；这些功能的入口仍在别处——网址导航 = 添加抽屉的网址导航页签、打开方式 = 设置 · 通用、搜索引擎 = 设置 · 搜索、显示与 Dock 类开关 = 个性化面板 + 模式胶囊、网格对齐线 = 设置 · 通用、更新记录 = 设置 · 关于。页面上的网站图标 / 图标文件夹 / 图标格容器保持不变。

## 开发

```bash
pnpm install
pnpm dev         # Vite 开发服务器（浏览器直接预览界面）
pnpm typecheck   # 类型检查
pnpm test        # 单元测试（layout / guards / bookmarks）
pnpm build       # 构建扩展 → dist/（Vite 出应用，esbuild 出 background）
pnpm release     # 打包 releases/
```

加载扩展：Chrome → `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择 `dist/` 目录。
