# Thrilled

新标签页扩展，极简冷调设计。

## 当前状态（v4.4）

- `v4.1` 起：**v4 功能重构完成**——React 18 + Vite + TypeScript，按「`app` 视图层 / `core` 服务层 / `background` / `shared`」分层；界面按 UiTab 实测基准复刻（`uetab.com`，见 04 文档），形态为「固定 1920 设计稿坐标系 + 60px 单元格绝对定位网格 + 横向翻页 + 风格皮肤系统 + 内容完全自定义」。
- **内容模型**：卡片 = 对小组件定义的一次引用 `{ id, c, r, w, h, t, config }`——位置与尺寸属于布局，`config` 属于内容；添加 / 删除 / 改尺寸 / 换类型 / 改内容 / 拖动 / 整套布局导入导出全部可用。见 [02-UI规格.md](docs/v4/02-UI规格.md) §13。
- **组件库与三层分工（4.4 起）**：**组件库**（个性化 → 第 4 个页签）管「放什么」——19 类组件按**信息 / 工具 / 内容 / 导航**四组浏览、已添加显示灰态、一键添加；页面上已放置的组件在此可**拖拽排序**（只改列表顺序，位置仍在页面上拖动）、切换**尺寸三档**（小 2×2 / 宽 4×2 / 大 4×4，映射到既有六档规范）与「··· → 配置 / 移除」，空页给出「页面暂无组件，从下面挑一个」。**个性化**管「长什么样」，**设置**管「怎么运作」。每个组件的配置 ≤5 项，分**通用**（名称 / 透明度跟随全局或单独覆盖）、**样式**（字号缩放 / 图标缩放 / 卡片圆角 / 文字颜色，四项对所有组件生效且按实例保存）与**专属**（每个组件 1–3 项：日历的显示年月与农历、天气的温度单位与区间、倒计时的节日倒数与吉祥物图形、木鱼的每次功课、倒数日的目标日期与强调色、热榜来源与条数滑杆、文件夹的显示名称…）；字段类型对齐 Storybook `argTypes.control` 词汇（text / num / list / bool / sel / **range** / **color**），后续组件加配置只需在定义表声明。**样式复用**：一键预设（紧凑 / 标准 / 宽松）、「设为该组件默认」（新放置的实例自动套用该类默认样式）、「复制到同类卡片」（同页同类型一次刷齐），默认样式随文档持久化并在设置归一化里做白名单与限幅。原「显示」页的时间 / 日期 / 每日一言开关已拆开：时间（含 12 / 24 小时与隐藏）与日期进时钟组件配置，每日一言由「组件是否存在」表达，Dock 快捷栏开关移到「背景效果」页签的「搜索与 Dock」卡。
- **本地持久化（4.1 新增）**：设置 / 布局 / 引擎 / 皮肤 / 搜索历史整存整取到 `chrome.storage.local`（浏览器开发预览回退 localStorage），改动防抖落盘；支持 v3 数据一次性迁移（磁贴 → 网址图标、引擎顺序、搜索历史、昵称等）。**纯本地运行**：不含任何云端同步 / 上传通道，数据只在本机（4.4 起移除云端同步与参考服务端）。
- **搜索引擎**：内置 12 个主流引擎（百度 / 必应 / 谷歌 / 搜狗 / 360 / 神马 / 夸克 / 头条 / 知乎 / 微博 / DuckDuckGo / Brave）+ 自定义；搜索框左侧图标即下拉入口，支持隐藏、拖拽排序。
- **风格皮肤**：内置经典 / 光感 / 暗黑 / 黑紫 / 晨曦 / 黛青六套仅为**出厂初始值**，12 项取色编辑器可自定义配色、改名、新建、删除、还原。**界面风格不做任何颜色限制。**
- **视觉体系（v4.4）**：纯净浅灰蓝默认背景，搜索框为唯一强焦点；单个网址图标无卡片化（品牌字形直落背景），**图标格容器内的图标保留标准方块容器**（行列按卡片尺寸自动铺满，见 shared/grid 的 `groupGrid`；格子多到装不下时容器转为可滚动，格子保持可辨识尺寸）；名称标签已**整体移除**（4.4 补丁 14：界面不再显示组件名，名称仅用作网址图标站点名与文件夹卡内名称）；卡片区 1776px（24 列 × 74px）居中于 1920 设计稿，搜索框底缘与首行卡片之间留 24px；小组件卡统一 16px 圆角 + 单一轻投影；Dock 玻璃磨砂悬浮栏（苹果式尺寸，快捷方式显站点 favicon、功能键显单色线性图标）；模式胶囊收起只显当前模式图标、悬停展开「极简 / 标准」两选项（无说明文字）；弹簧动效、卡片入场渐次浮现、弹窗缩放入场。
- **组件尺寸自适应（4.4 补丁 12）**：卡片自身就是 CSS **查询容器**（`container-type:size`），组件排版用容器查询单位表达——`--u = max(1px, min(100cqw / 自然宽, 100cqh / 自然高)) × 字号缩放` 即「1 设计像素」。**自然尺寸下 --u = 1px**（渲染与设计稿逐像素一致），比自然尺寸大的卡片按短边比**等比放大**（字体、图标、图标格容器、圆角、内外间距全部跟随；实测图标卡 2×2 → 4×4 时图标 60 → 151px），更小的卡片保持设计字号不缩小（出厂布局本就把时钟放在 4×2 等小档位）。细则：**尺寸能力**——每类组件声明最小 / 最大档位（`WidgetDefinition.min/max`，仿 react-grid-layout 的 minW/minH），组件库三档、配置弹窗六档与右键「修改尺寸」都据此置灰或过滤，store 兜底拦截（新闻 / 纪念日 / 倒计时 4×4 起、日历 / 天气 / 待办 / 翻译 / 计算器 4×2 起、音乐 4×4 起、时钟 4×2 起、图标格容器 4×2 起），并**按实例内容再收紧**——图标格容器按应用数与标签条带算出「该档能否不滚动装下」，装不下的档位直接置灰；**宽卡扩展**——卡片宽度 ≥ 420px 时天气卡多显示一行「明日温度」、倒数日卡多显示目标日期（窄卡自动隐去，出厂尺寸外观不变）；**密度降级**——窄卡按 @container 查询减信息而非压字号（< 420px 隐倒计时熊猫与纪念日日期、< 300px 隐新闻热度值、< 140px 的 2×2 只留 AI 徽标 / 语录行）。
- **壁纸（v4.4）**：系统不内置任何壁纸资源；「我的壁纸」支持本地上传（图片压缩 1920px / 最大 5MB）、外链上传与视频壁纸（mp4 / webm）；「壁纸来源」统一适配器架构接入多个外部壁纸网站——Wallhaven / Picsum / 必应每日 / 061129 精选 / 哲风五种协议适配器（同构 API 可改基址接镜像）；「壁纸」面板合并为一张卡片：顶部缩略图 + 名称与体积一行，下方来源列表单行承载——**点行名预览该源**（当前项标「预览中」）、开关控制启用禁用、行尾「···」改地址或移除，列表末尾文字入口「+ 添加来源」补入尚未添加的来源；支持关键词搜索（Wallhaven 服务端搜索、061129 客户端关键词过滤，由适配器声明提供），按来源原有分类浏览（Wallhaven 的 General/Anime/People、061129 的插画/动漫/风景…原站结构），点击即下载原图落地 IndexedDB（20MB 上限）并设为壁纸（图片经 `<img>` 全窗口铺满渲染，不走 CSS 变量，避免超长 dataURL 触发浏览器声明长度上限）；等待期间网格上覆盖应用任务浮层，按「正在下载壁纸（字节进度）/ 正在处理图片 / 即将应用」三段反馈，含进度条、循环等待环与步骤条，总量不可知时自动转为循环扫光；请求经 SW 后台代理绕过跨域，开发预览回退直连。**自适应**：图片经 `object-fit:cover` 等比填满（不变形、无黑边），裁剪位置不再固定居中——按视口宽高比自动挑主体最集中的窗口（降采样灰度 + Sobel 边缘能量 + 中心先验 + 明度方差滑窗评分）写入 `object-position`，竖屏 / 改窗口 / 换屏时自动重算。**去重与历史**：IndexedDB 主键改为源地址哈希（本地上传用图片内容哈希），同一张图命中即跳过整段下载；「壁纸」面板带横向历史缩略图带，保留最近 12 张，点缩略图直接切换；标题行右侧「清空历史」一键清理全部历史记录（当前使用中的那张保留，二次确认后连本机图片一起删除）。来源可用性均经 HTTP 状态码实测验证；哲风壁纸在用户明确授权的例外下接入（按站方公开前端使用的传输协议实现，原图下载需登录站方账号，故以站方裁剪图为图源）。
- **透明度与毛玻璃（v4.4）**：两组**独立**设置，互不影响。透明度 12 项——玻璃底色 6 项（卡片 / 图标容器 / Dock 快捷栏 / 搜索框 / 面板与弹窗 / 菜单与浮层，保留可读下限）与元素显隐 6 项（图标图形 / Dock 图标 / 时间与日期 / 每日一言 / 边框与分隔线 / 悬停与激活态，可一路调到消失），另有全局透明度叠加。毛玻璃模糊 6 项（0–20px，与有玻璃底色的六个透明度项一一配对）：只降透明度不调模糊会「透但看不清」，两组配对才通透。每项名称右侧的 ⓘ 悬停 200ms 或点击展开作用范围说明，气泡逼近面板右缘时自动向左翻转。
- **真实数据**：天气卡接 Open-Meteo 实况（30min 缓存，定位超时降级北京）；搜索 / 卡片 / Dock / 导航点击经 `core/link-opener` 按打开方式设置真实跳转。**卡片点击直达详情（4.4 补丁 13）**：图标卡点击开站，其余各类小组件点击打开「详情」弹窗展示核心内容——天气（实况 + 三日预报 + 刷新）、时钟（实时走字 + 12/24 小时 / 秒数 / 日期快捷开关）、日历（当月月历网格、今日高亮）、待办（可勾选 / 添加 / 删除的真实清单，存卡片 config.items）、收藏夹（浏览浏览器书签、按打开方式跳转）、倒数日 / 纪念日 / 下班倒计时（大字天数与实时倒计时）、热榜全榜、每日一言（换一句）、木鱼（功德 +N）、音乐电台控制、图标格容器应用清单（点击开站）；数据模型还没有的部分（农历 / 计算器 / 翻译 / AI）如实注明占位；弹窗底部「编辑配置」与编辑互通。**待办清单条目直接外显在卡上**（勾选框可点，超出的显示剩余条数）；**下班倒计时内置节日倒数列表**（元旦 / 春节 / 清明 / 劳动节 / 端午 / 中秋 / 国庆自动取下一次发生 + 自定义倒数日，按剩余天数排序、带进度条；发薪 / 工资类演示占位已移除；熊猫吉祥物可换 emoji 或隐藏）；**收藏夹详情为 4 列图标瓦片网格 + 名称 / 网址过滤**；所有卡片拖拽加 4px 阈值，点按不触发位置变动。
- **Dock（4.4）**：出厂快捷方式为空、由用户手动新增——「添加」抽屉自定义页签勾选「同时添加到底部 Dock」；快捷方式图标显示站点 favicon（失败回退品牌字形），右键可打开 / 修改名称 / 修改网址 / 从 Dock 移除（`settings.dockApps`，`{name,url}` 结构）；右侧固定三个功能键：新增 / 个性化 / 设置（右上头像已移除）；悬停按指针接近度苹果式放大。侧边抽屉直角样式；「添加」抽屉网址导航展示真实 favicon（失败回退品牌字形）。**从书签快速添加（4.4 补丁 13）**：网址导航页签在预设分类后追加「书签」分类（读 chrome.bookmarks，条目带真实网址，分类尾部「全部导入」复用 placeMany 通道，为批量导入预留扩展位）；自定义页签新增「从书签快速添加」——展开书签列表（可按名称过滤）逐条点击即添加为主界面网址图标快捷方式。
- **三面板（纯本地，4.4）**：添加（网址导航分类 / 自定义+图标上传+文件夹；小组件入口已统一到组件库）、个性化（无副标题单行头部；壁纸 / 背景效果 / 主题 / 组件库 四个页签——背景效果 = 透明度 / 毛玻璃模糊 / 壁纸与文字 / 搜索与 Dock，主题 = 风格皮肤 + 风格编辑器 + 显示，主题缩略图一排 4 个 + 12 项色值 4 列密排）、设置（与个性化同一套分布方式：搜索 / 通用 / 数据 / 关于 四个分区页签，各模块以卡片分组，说明收进标题 ⓘ，危险操作单独成卡并标红）；欢迎选风格 / 添加引擎 / 备份 / 恢复 / 一键重置弹窗齐备，重置类操作均二次确认；更新记录不再用弹窗，直接内联在设置 → 关于。登录与账号体系、云端同步与「关于我们」均已移除（个人使用阶段，数据只在本机）；在线广场（模板分享）已整体移除，个性化里的主题（风格皮肤）不受影响。
- **设置分区（4.4 改版）**：分区按使用频率 × 风险排序——**搜索**（引擎清单拖拽排序 / 启用 / 隐藏 + 添加自定义；搜索框：占位文字可自定义、引擎图标可隐藏、点图标可选「展开列表 / 切换下一个」、自动聚焦 / 保留搜索内容 / 隐藏搜索按钮 / 搜索历史 / 显示单条删除四个开关、历史保留条数 4–20、字号 13–20px 与距顶 20–44px（只能上收）、回车与点放大镜可分别指定打开方式、搜索后自动失焦、「清空搜索历史」一键清理）、**通用**（打开方式互斥单选 + 每日问候昵称）、**数据**（备份与迁移：3 列等宽网格、按作用域分两行——界面级「备份当前界面 / 恢复本地快照 / 恢复为默认界面」、文件级「导出布局 JSON / 导入布局 JSON / 导入收藏夹」，全组只有「备份当前界面」是主按钮；重置与清理：清除本地数据 / 一键重置，红色标识且贴面板底部、两颗各占 1 格与上卡逐列对齐，与上方以空白隔离带拉开距离，隔离带中部是一条状态行「上次备份：MM-DD HH:mm + 查看快照」把空白改成信息区）、**关于**（更新记录：版本单行表头「4.4 · 日期区间 · N 项」+「当前」chip，旧版本折叠成一行点击展开；条目为「类型标签 + 一句摘要」，实现细节点条目展开；快捷键：11 个动作全部可改键，点键帽后按新组合键、Esc 取消、Backspace 清除、冲突拦截，可一键恢复默认）。卡片内主按钮在前、低频动作退到第二行，说明文案统一收进标题右侧 ⓘ（支持换行清单，作用域易混的操作如「恢复本地快照 / 恢复为默认界面 / 一键重置」在此写明范围）。
- **v3 能力接回**：收藏夹导入（书签树 → 网址图标）、本地目录同步（File System Access，数据写盘 / 恢复）、导出导入布局 JSON、快捷键（设置 → 关于里可自定义，出厂值：`/` 聚焦搜索框、`←→` 翻页、`Alt+M` 切模式、`Alt+A`/`Alt+P`/`Alt+S` 开面板、`Alt+Q` 换鼓励语、`Ctrl+Shift+E` 导出、`Ctrl+Shift+R` 重置、`Esc` 关浮层）。

## 目录结构

```
src/
├─ app/            React 视图层（不直接碰 chrome.*）
│  ├─ main.tsx     入口（装配 platform 平台注入）
│  ├─ App.tsx      舞台装配：搜索 / 翻页网格 / Dock / 模式胶囊 / 浮层
│  ├─ store.ts     zustand：设置 · 布局 · 引擎 · 皮肤 · 持久化（hydrate/scheduleSave）
│  ├─ layout.ts    出厂布局 + 导入归一化（栅格算法在 shared/grid）
│  ├─ widgets.tsx  小组件渲染器（定义表在 shared/widget-defs）
│  ├─ panels.tsx   抽屉（添加/个性化/设置）+ 弹窗 + 皮肤编辑器
│  ├─ menus.tsx    右键菜单（全局 9 项 / 卡片 6 项）
│  ├─ brands.ts    品牌色字形 + 站点 URL 注册表
│  ├─ platform.ts  core 层 UI 回调注入（file-config 等）
│  ├─ icons.tsx    图标集
│  └─ styles/      令牌与样式（来自 docs/v4/index.html 冻结原型）
├─ core/           框架无关服务层：storage（v4 文档 + kv）/ wallpaper（IndexedDB）/
│                  file-config / favicon / export / reset / migrate（v3→v4）/
│                  weather / quotes / search 链接打开 / bookmark-importer / logger / errors / utils
├─ background/     service worker（index.ts + favicon-resolver.ts）
└─ shared/         类型 · 常量 · 默认值（皮肤 / 设置 / 快捷键）· 网格算法 · 小组件定义表 · 消息协议
```

**分层铁律**：`core/` 与 `background/` 不 import React；`app/` 不直接调用 `chrome.*`，一律经 `core/`。

## 开发

```bash
pnpm install
pnpm dev         # Vite 开发服务器（浏览器直接预览界面）
pnpm typecheck   # 类型检查
pnpm test        # 单元测试（layout / guards / bookmarks）
pnpm build       # 构建扩展 → dist/（Vite 出应用，esbuild 出 background）
pnpm release     # 打包 releases/
```

加载扩展：Chrome → `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择 `dist/` 目录。
