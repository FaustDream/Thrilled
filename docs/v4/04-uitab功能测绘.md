## 1. 产品定位（✅）

> 国内第一个原创横屏交互，真正的浏览器桌面，几乎还原桌面交互的体验跟功能。免费无广告。

**结论**：桌面隐喻——**小组件与网站图标同处一个自由网格，绝对定位、可跨格、可拖拽、可横向翻页**。不是「分区固定三段式」，也不是简单的图标网格。

## 2. 布局引擎（✅ 已完整实测，本次最重要的发现）

这是复刻的关键。实测视口 `1920×945`，DOM 结构与坐标如下。

### 2.1 顶层结构

```
div.fixed.w-screen.h-screen.overflow-hidden            ← 全屏舞台，scrollWidth = 3840 = 2 页
└─ div.h-full.absolute.left-0.top-0.transition-all     ← 翻页画布（横向平移 + transition）
   ├─ (1) 空容器                                         0,0   1920×0
   ├─ (2) 搜索栏行  absolute w-full h-[50px]            0,100 1920×50
   ├─ (3) 主网格    absolute w-full top-1/2 translateY  0,150 1920×644  ← 垂直居中
   └─ (4) Dock 栏   absolute bottom-0 w-full p-4        0,823 1920×122  ← 固定底部
```

### 2.2 网格规则（✅）

| 项 | 实测值 |
| --- | --- |
| 单元格边长 | **60px** |
| 卡片绘制方式 | 每个卡片在自己占用的单元格块内**四边内缩 25px** ⇒ 实际尺寸 = `单位数 × 60 − 50`，相邻卡片净间距 50px |
| 横向规模 | **24 列 × 60px = 1440px**，水平居中（1920 视口下两侧各 240px） |
| 纵向规模 | 约 10 行（600px），以视口垂直中线（`top:50% translateY(-50%)`）对齐 |
| 是否为响应式流式 | ❌ **不是**。画布是**固定 1920 宽**的设计稿坐标系；不同窗口尺寸下整块画布按比例缩放 |
| 翻页 | 画布宽度 ≥ 2 屏，`overflow:hidden` + 横向平移。**未观察到可见分页圆点** ⚠️（翻页由滚轮/拖拽触发，待补测） |

### 2.4 坐标换算（页面 1 实测）

- 网格原点：`x = 264`（第 0 列卡片左上角）、`y = 196`（第 0 行卡片左上角）
- 列坐标：`264 + 60n`（n 为偶数列，因为卡片最小 2 单位宽）
- 行坐标：`196 + 60m`，实测行命中 `196 / 436 / 557 / 677`（= 第 0、4、6、8 行）
- 页面 2 的所有卡片 = 页面 1 坐标 **+1920px**（即每页按一屏宽度排布）

### 3.4 图标格容器（AI工具合集 / 购物 / 影音 / 游戏 / 社交 共用）

✅ 实测：容器背景 `bg-bg3`，内部为**绝对定位的 90×90 单元格阵列**（`transition: width/height .3s`，外层用 `transform: scale() translate()` 适配容器尺寸）。

- 4×4 容器：内部画布 180×180，单元格 90×90，padding 15px ⇒ 2×2 图标
- 4×2 容器：内部画布 180×90 ⇒ 2×1 图标
- 8×4 容器：内部画布 450×180，`scale(0.8) translate(20px,20px)` ⇒ 5×2 图标

**结论**：这是**「图标分组容器」**——用户可以建一个 2×2 / 4×2 / 5×2 的组，把网站图标放进去。

### 3.5 网址图标（2×2）

✅ 实测 DOM：`ant-spin` 加载态 + `div.bg-center.bg-no-repeat`（背景图方式渲染站点图标）+ 卡片下方 **14px 白色居中文字标签**（`opacity:1`，**常驻可见**，不是 hover 才出现）。

| 项 | 取舍 |
| --- | --- |
| 搜索联想（候选词 / 热搜提示 / 提示词胶囊） | ❌ **不做**。只保留可开关的搜索历史，关闭后搜索框不弹任何下拉；补充 v3 的搜索框设置（自动聚焦 / 保留搜索内容 / 隐藏搜索按钮）与数字键 `1`–`9` 切换引擎 |
