## 1. 设计基准

**一比一复刻 UiTab 新标签页**（依据见 04 文档，全部来自真实 DOM 实测）。三条硬事实决定了本规格：

1. **不带分区**：小组件与网站图标**同处一个绝对定位网格**，混排、可跨格
2. **卡片不是毛玻璃**：实测为**不透明白底 + 16px 圆角**，名称标签 **14px 白色居中**、常驻显示在卡片下方
3. **固定设计稿坐标系**：画布按 1920 宽设计，横向 24 列 × 60px = 1440px 居中，卡片在单元格块内四边内缩 25px

在此基础上保留 Thrilled 自有品牌与素材（见 04 §7）。

## 2. 三种模式

| 模式 | 保留内容 | 隐藏内容 |
| --- | --- | --- |
| **极简** | 搜索框 + 大时钟 + Dock | 网格内全部卡片、名称标签、翻页 |
| **标准** | 全部内容 | — |
| **隐私** | 搜索框 + Dock + **隐私自己的整套页面** | 标准模式的内容（隐私是独立页面集，不是把标准页模糊） |

- 入口：左上角 `40,16` 处的**胶囊容器**，默认收起（显示一个图标），**悬停展开**才显示「极简 / 标准 / 隐私」三个按钮；展开时每个按钮上方显示该模式的说明句（极简「简单可靠的网络访问」/ 标准「灵活的拖拽&极致的响应交互」/ 隐私「链接都将从隐私窗口打开」）
- 右键菜单中的「极简模式」为同一开关的第二个入口
- 模式属于本地设置，不参与云同步
- **隐私模式（✅ 已取证，修正旧方案）**：标准与隐私**各自独立的页面集**（源码 `"standard"===e.mode?e.standardPage:e.privacyPage`），**每种模式最多 5 页**（`应用最多添加 5 页`）；进入需登录（`登录后才能进入隐私模式`）；隐私数据按账号隔离（`不同账号再次登录处于安全考虑会清空隐私数据`）；隐私模式内的链接从隐私窗口打开。**原「模糊 + 不可交互」方案作废。**

## 3. 布局引擎（复刻核心）

### 3.1 坐标系

```
舞台  100vw × 100vh，overflow:hidden
└─ 翻页画布（横向平移，transition）
   ├─ 搜索栏行      y = 100px，高 50px，水平居中
   ├─ 主网格        top:50% translateY(-50%)，高约 644px（垂直居中）
   └─ Dock 栏       bottom:0，高 122px，padding 16px
```

| 项 | 值 |
| --- | --- |
| 设计稿宽度 | **1920px 固定**（非响应式流式；窗口变小则整体缩放） |
| 单元格 | **60px** |
| 卡片绘制 | 四边内缩 25px ⇒ `实际尺寸 = 单位数 × 60 − 50` |
| 网格规模 | 24 列 × 10 行 |
| 网格原点（页面 1） | 第 0 列 `x=264`（含内缩），第 0 行 `y=196` |
| 翻页 | 每页宽 1920px；页面 N 的卡片坐标 = 页面 1 + `N×1920` |
| 名称标签定位 | 标签高 20px，顶边 = `(row + h) × 60 − 24`（紧贴卡片底边下 1px），左 = `col × 60`、宽 = `w × 60` |

### 3.2 尺寸档位

| 单位 | 像素 | 用途 |
| --- | --- | --- |
| 2×2 | 70×70 | 网址图标 |
| 2×4 | 70×190 | 收藏夹 |
| 4×2 | 190×70 | 天气 / 待办 / 日历 / 游戏 / 社交 |
| 4×4 | 190×190 | 时钟 / 熊猫Dj / 购物 / 影音 / UiTab AI |
| 8×4 | 430×190 | 新闻热点 / AI工具合集 / 下班倒计时 / 纪念日 |

### 3.3 分期（保留「先简单后难」，但终态即 UiTab 形态）

| 阶段 | 内容 | 说明 |
| --- | --- | --- |
| **P1 一期** | 固定坐标网格 + 横向翻页 + 拖拽换位 | 位置存 `{col,row}`，卡片按单位尺寸渲染。**已是 UiTab 的实际形态** |
| **P2 二期** | 自由拖拽绝对定位 + 碰撞推挤 + 图标分组容器 | 补 3.4 的分组容器与自动避让 |
| **P3 三期** | 缩放卡片、多页管理、贴边吸附、对齐辅助线 | 桌面隐喻的完整实现 |

**统一接口约定**

```ts
/** 卡片实例：引用某个小组件定义 + 自己的配置（见 §13 内容模型） */
interface GridItem {
  id: string
  /** 网格单位坐标与尺寸（1 单位 = 60px，卡片实际尺寸 = 单位×60 − 50） */
  c: number
  r: number
  w: number
  h: number
  /** 引用的小组件类型 = WIDGET_DEFS 的键 */
  t: WidgetKind
  /** 只存本实例的覆盖值；读取时按「定义默认值 ⊕ 实例覆盖值」合成 */
  config: Record<string, unknown>
}

interface GroupCardConfig {
  cols: number                       // 内部图标格列数（单元格 90×90，padding 15px）
  apps: string[]                     // 应用名列表
}

interface WidgetField {
  k: string                          // config 键
  l: string                          // 显示名
  t: 'text' | 'num' | 'list' | 'bool' | 'sel'
  o?: string[]                       // sel 的选项
  ph?: string                        // 占位提示
}

interface WidgetDefinition {
  t: WidgetKind
  n: string                          // 显示名
  g: string                          // 字形（占位素材）
  c: string                          // 品牌色
  s: string                          // 一句话说明（添加面板副标题）
  units: [number, number]            // 默认单位尺寸 [w, h]
  fields: WidgetField[]              // 可编辑字段（编辑弹窗据此渲染）
  def: Record<string, unknown>       // 默认配置
}
```

**倒计时是「单卡片多条目」**——这是一个 8×4 卡片内含 1 条主计时 + 2×2 条目格，不是四个独立卡片。

## 6. 风格皮肤系统与壁纸

### 6.1 风格 = 一整套界面令牌（用户资产）

**界面风格不做任何颜色限制。** 风格皮肤是用户可完全自定义的数据资产，不是设计系统的约束对象；项目不为风格预设可用/禁用的颜色。任何一色都可能出现在皮肤里——那是用户的选择。

**风格皮肤系统**：内置 **经典 / 光感 / 暗黑 / 黑紫** 四套，仅为**出厂初始值**，与用户自建风格同构，可改名、可改色、可覆盖、可删除、可新建副本。不存在「锁定不可删」的官方皮肤。

| 内置风格 | 设计取向 |
| --- | --- |
| 经典 | 浅色壁纸 + 白底卡片 + 深色文字 |
| 光感 | 浅色高亮、卡片更透、青色强调 |
| 暗黑 | 深色底 + 深色卡片 + 浅色文字 |
| 黑紫 | 深黑底 + 紫色强调（卡片底、选中态、按钮） |

**风格包结构**（`id` 为自由字符串，由文件名或时间戳生成；`builtin` 仅标记出厂来源，不影响可编辑性）：

```ts
interface SkinPack {
  id: string                 // 自由 id，不再限定为字面量联合
  name: string               // 用户可改
  builtin: boolean           // 出厂初始值 → 可「还原内置」；自建风格无此操作
  base: 'light' | 'dark'     // 仅决定文字与图标的对比基线，不限制配色
  tokens: Record<string, string>   // 完整令牌集，见 9.1；缺省项回退 base 默认值
  wallpaperId?: string
}
```

**用户可编辑的令牌**（风格抽屉「风格」tab，12 项取色 + 名称输入，改动即时生效并保存到该风格）：

| 分组 | 令牌 |
| --- | --- |
| 卡片 | `--card-bg` 卡片背景、`--card-text` 卡片文字、`--card-sub` 次要文字、`--accent` 强调色 |
| 名称 | `--label-color` 名称标签颜色 |
| 面板 | `--panel-bg` 面板背景、`--panel-text` 面板文字、`--line` 边框线 |
| 浮层 | `--chip-bg` 胶囊底、`--chip-text` 胶囊文字、`--menu-bg` 菜单底、`--menu-hover` 菜单悬停 |

**风格管理操作**：新建风格（复制当前风格为新副本）、还原内置（仅 `builtin` 风格可用）、删除当前（至少保留 1 套）、修改名称（自由文本）。

**同步与导出**：`SkinPack` 全量随设置一起云同步与导出，是用户数据的一部分；多端冲突时按整体风格粒度取舍，不合并令牌。

### 6.2 壁纸

分类：**极简 / 动漫 / 风景 / 更多**。支持用户上传图片与视频（视频存 IndexedDB `thrilled-wallpaper`，见项目硬约束）。壁纸可从所属风格自动带出，也可单独指定覆盖该风格。

### 6.3 欢迎弹窗（首次访问）

- 标题「欢迎来到 Thrilled」，副标题一句话说明「选择风格来搭配组件和图标」
- 4 张风格卡片（**预览图为自绘示意图**，非 UiTab 作品）
- 主按钮「应用风格」

### 6.4 透明度与玻璃质感（两个维度，都由用户调）

**两个维度互不干涉**——透明度决定「能不能看见背后」，玻璃质感决定「背后糊不糊」。

| 维度 | 粒度 | 控制 | 换算 |
| --- | --- | --- | --- |
| **透明度** | **全局一个** | 个性化 → 透明度（20–100%，默认 100%） | `--g-alpha` 同时缩放**所有面**的背景 alpha |
| **玻璃质感** | **分功能 6 条** | 个性化 → 玻璃质感（每条 0–100%） | 该面 `alpha = 1 − 0.55 × 值`、`blur = 26px × 值`；**0% = 该面回到不透明纯色平面** |

**六个可调区域**（默认值）：卡片 60% · 图标容器 35% · Dock 栏 70% · 搜索框 45% · 面板与弹窗 65% · 菜单与浮层 65%。

**覆盖范围**：卡片（资讯卡与小组件卡）、图标容器（网站图标 / 图标格容器 / Dock 图标）、Dock 栏、搜索框、面板与弹窗（抽屉 / 弹窗 / 搜索建议）、菜单与浮层（右键菜单与二级菜单 / 模式胶囊 / 提示气泡）。

**硬约束**：透明度只作用于「面」的背景，**文字与图标始终不透明**，任何档位下都可读；壁纸层另带一层极细斜纹（`repeating-linear-gradient`），作为玻璃质感的参照物——没有可被模糊的细节，毛玻璃就不成立。

**实现约定**：按令牌取色的面写成 `color-mix(in srgb, <颜色令牌> calc(var(--g-alpha) * var(--ga-<面>) * 100%), transparent)`，模糊写 `backdrop-filter: blur(var(--blur-<面>))`；`--ga-*` / `--blur-*` 由 `applySkin` 依据 `state.glass` 统一写入。Dock 栏与搜索框不再有独立的透明度滑杆（原「栏透明度 / 搜索框透明度」并入玻璃质感，避免同一件事两个旋钮）。

**底部 Dock 的视觉处理**：应用与功能按钮共用统一图标容器（§12.2），栏体加 `inset` 顶部高光 + 投影，分隔线取 `--label-color` 的 28%。

## 12. 三份冻结规范（栅格 / 图标容器 / 命名）

> 冻结于 2026-09-26。三份规范管住「能放什么、怎么画、怎么叫」，后续所有页面与组件不得越过。

### 12.1 栅格规范（沿用实测，不重建）

| 规则 | 值 |
| --- | --- |
| 单元格 | **60px**；网格 **24 列 × 10 行**（1440×600），水平居中、垂直居中 |
| 卡片绘制 | 所在单元格块**四边内缩 25px** ⇒ 尺寸 = 单位×60 − 50 |
| **允许的卡片尺寸** | **仅 2×2、2×4、4×2、4×4、8×4、8×2** 六档；不允许任意尺寸 |
| 分区带 | 每页分三带：第 0–3 行 / 第 4–7 行 / 第 8–9 行（96 + 96 + 48 = 240 格） |
| 填满要求 | **每页必须 100% 填满**，不允许半行留白；填不满就换卡片尺寸或改用图标格容器 |
| 名称标签 | 顶边 = `(row + h) × 60 − 24`，左 = `col × 60`，宽 = `w × 60`；常驻显示 |
| 越界与重叠 | 硬禁止（实现层已有校验：越界 0、重叠 0） |

> 说明：评审稿建议的「重建 4/6 列栅格」不采纳——原判断「列宽由内容决定」经实测证伪（栅格恒定 60px，宽度差异来自卡片占 2/4/8 个单位）。重建栅格会推翻已验证的 25px 内缩与标签公式，收益为负。

### 12.2 图标容器规范（全站唯一一种图标语言）

| 规则 | 值 |
| --- | --- |
| 容器 | **白底 + 细边框 + 轻投影**：`#fff` / `1px solid rgba(15,23,42,.07)` / `0 2px 6px rgba(6,12,24,.10)` |
| 图形 | **品牌色字形**（当前占位素材为品牌色首字，替代真 Logo）；**不再使用「品牌实底 + 白字」第二套语言** |
| 圆角 | 小容器（边长 ≤ 48px，网格图标 / 图标格容器）**14px**；大容器（Dock 图标 66px）**20px** |
| 字号 | 小容器 24px、图标格内按容器实算（约边长×0.34）、Dock 30px；拉丁字形按 0.74 缩放 |
| 功能按钮 | 与站点图标**同一容器**，只把图形换成线性图标（Dock 四个按钮各用自己的强调色描边） |

### 12.3 命名规范

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 站点入口 | 一律用**服务名**（品牌名），不用意象名、不用功能描述 | 「京东」「Notion」「V2EX」 |
| 功能入口 | **功能名 + 一句副标题**（说明做什么） | 「计算器 / 科学计算 · 单位换算」「AI 助手 / 由大语言模型提供支持」 |
| 图标格容器 | 用**分区名**（资讯 / 工具 / 娱乐 / 电商 / 开发 …），不堆砌 | 「AI 工具」「影音」「购物」「开发」 |
| 一服务一入口 | 同一服务在**整个网格内只出现一次**；Dock 常驻的服务（音乐 / 哔哩哔哩 / 淘宝 / 抖音 / 小红书 / 影视 / 百度网盘）**不再出现在网格里** | 实测：页内重复 0、与 Dock 重复 0 |
| Dock 与网格的关系 | **Dock = 常驻高频快捷；网格 = 分区导航**。Dock 是同一服务的常驻副本，除此之外不得再有第二入口 | 见上 |

**内容编排规范**：标准模式两页按**任务分区**（资讯与日程 / AI 与工具 / 娱乐与电商 / 时间与纪念 / 开发与效率），AI 类入口收敛为第 1 页 4 个（+ 第 2 页 10 个「更多 AI」），不再出现 8 个入口表达同一件事的情况。

## 13. 内容模型（小组件引用）

> 2026-09-26 落地于原型。核心诉求：**布局保持现状不变，内容完全自定义**。

**一句话**：卡片不是一段写死的内容，而是**对某个小组件定义的一次引用**——位置与尺寸属于布局，`config` 属于内容。

### 13.1 定义表 `WIDGET_DEFS`（18 类，唯一来源）

| 类型 `t` | 显示名 | 默认单位 | 可编辑字段（原型已实现） |
| --- | --- | --- | --- |

| `clock` | 时钟 | 4×4 | 显示秒数（bool） |
| `cal` | 日历 | 4×2 | — |

| `todo` | 待办清单 | 4×2 | 清单名称（text） |

| `countday` | 倒数日 | 4×2 | 标题、剩余天数 |

| `fav` | 收藏夹 | 2×4 | 收藏夹名 |

| 类型 | 控件 | 写入 |
| --- | --- | --- |
| `text` | 文本输入 | 字符串 |
| `num` | 数字输入 | 数字（空值按 0） |
| `list` | 文本输入，逗号分隔 | 数组（中英文逗号都能拆） |
| `bool` | 开关 | 按合成后的有效值取反 |
| `sel` | 选项胶囊 | 选项字面量 |

编辑弹窗（右键「编辑信息」/ 卡片悬浮铅笔）**完全由定义表的 fields 渲染**；输入即时写入实例并刷新卡片，「确认修改」只做收尾。输入过程中不重绘网格，避免丢焦点。

### 13.3 增 / 删 / 改 / 换 / 拖动 / 导入导出

| 操作 | 入口 | 规则 |
| --- | --- | --- |
| 添加 | 添加抽屉（小组件 / 网址导航 / 自定义） | 按定义默认尺寸落位；当前页满则**自动新建一页**（每种模式最多 5 页） |

| 改内容 | 编辑弹窗 | 字段 → `config`，只存覆盖值 |
| 换类型 | 右键「更换小组件」 | 保留位置、尺寸与名称标签，`config` 回到新定义默认值 |

| 导入 / 导出 | 设置 → 数据与备份 | 导出 `{ v, app, exportedAt, standard, privacy }`；导入兼容「多页」与「扁平单页」，坏数据丢弃并提示 |

### 13.4 出厂布局与用户布局分离

- 出厂布局冻结在 `DEFAULT_PAGES`（标准两页 + 隐私一页，填满要求见 §12.1），**用户改动只影响实例**
- 「恢复为默认界面」「一键重置」= 从 `DEFAULT_PAGES` 重新种入（布局 + 内容一起回到出厂）
