## C. 明确不做（含理由）

| 编号 | 不做的事 | 理由 |
| --- | --- | --- |
| C1 | CRDT / 实时协同编辑布局 | 单人单账号多设备场景，无并发编辑需求，复杂度与收益严重不匹配 |
| C2 | 离线操作队列与冲突自动合并 | 一期为快照式，二期为乐观锁 + 手动选择保留哪端，够用 |
| C3 | 开放注册与公开分享广场 | 用户明确「仅自己用」；开放后需引入审核、滥用防护、内容合规，成本远超收益 |
| C4 | 加载远程 JS 小组件 | Chrome MV3 CSP 硬禁止远程代码执行 |
| C5 | 加载远程 HTML 片段作为模板 | 同上，且引入 XSS 面；模板只传结构化数据 |
| C6 | 二进制壁纸（尤其视频）上云 | 存储与带宽成本高，且本地 IndexedDB 已能满足；跨设备用引用而非实体 |
| C7 | 公网攻击者防护加固（WAF、防 DDoS、多租户隔离） | 个人使用场景，与两个现有项目的 `AGENTS.md` 约束一致：不为假设性风险增加复杂度 |
| C8 | 同时使用 React 与 Vue | 双运行时、双构建配置，维护成本翻倍，零收益 |
| C9 | 服务端渲染（SSR） | 扩展新标签页是纯客户端场景，SSR 无收益 |
| C10 | 自建账号密码体系（第二套账号） | 云笺集账号已是唯一真相源，再造一套会导致账号分裂与同步错乱 |
| C11 | 黄历小组件 | UiTab 小组件全集（04 §5.1 源码枚举 19 类）中无「黄历」，为原方案自拟项，移除。**注**：同表中的「每日一言 / 经典语录」确为 UiTab 真实小组件类型，已实现为 `quote` 卡 |
| C12 | 复用 UiTab 的任何素材（图标、吉祥物、壁纸、广场预览图） | 版权原因，一律自绘或用自有素材（04 §7） |
| C13 | **搜索联想（候选词）** | 用户明确「目前不做」：聚焦与输入都不出候选词，也不做热搜提示与提示词胶囊；只保留**可开关的搜索历史**（关闭后搜索框不弹任何下拉），见 02 §11 |
| C14 | v3 的「分组（分类分页）」 | 由 v4 的绝对定位网格 + 横向翻页替代（用户已定），不再保留分类 Tab 与「分类记忆」设置 |
| C15 | 逐格复刻 UiTab 的**页面内容** | 机制照实测复刻，但内容编排按任务分区重排（同卡混类、一服务多入口、AI 类 8 入口重复，属原产品 IA 问题），见 02 §12 与 04 §7。复刻版存档 `index-uitab.html` |
