## 浅色主题修正（本轮第四批）

用户指出「经典主题为什么是深色的，不应该是浅色吗」。根因两条：

1. 经典皮肤的 `wall: 0` 指向深色的「默认壁纸」；`state.wall` 初值也是 0，所以不点欢迎弹窗时页面一直是深色。SKIN_DEF 里每套皮肤的 `wall` 字段只在**欢迎弹窗预览**与 `theme-apply` 里被读过，`skin-pick`（个性化里的风格卡）没有带出配套壁纸，`boot` 也没有同步。
2. 即使换成浅色壁纸，**落在壁纸上的元素仍是白色前景**：名称标签 `--label-color:#ffffff`、翻页圆点写死 `rgba(255,255,255,.45)`、顶部胶囊 `--chip-text:#ffffff`、搜索框 `--search-text:#ffffff` 与白色 placeholder、以及写死近黑的遮罩层 `rgba(6,10,16,·)`——白字白底等于看不见。

修法：

- 新增浅色壁纸**「云白」**（`WALLS[6]`，极简分类）并绑定给经典（`base` 改浅色 `#eef2f8`、`wall: 6`）
- `applySkin(id, syncWall)`：**只在切风格时**带出配套壁纸（boot 与 `skin-pick` 传 `true`），单独选壁纸/调遮罩不会把壁纸顶回去
- 经典与光感（同为浅色主题）的前景令牌改深色：`--label-color` / `--chip-text` / `--search-text` / `--search-ph`
- `.page-dot` 改为 `background:var(--label-color)` + `opacity` 区分选中（不再写死白色）
- 遮罩层改为 `background:var(--mask-color);opacity:var(--wp-mask)`，浅色主题 `#ffffff`、深色主题 `#060a10`（新增内部令牌，不占皮肤编辑器 12 项）
- 顺带把欢迎弹窗文案对齐 02 §6.3：标题「欢迎来到 Thrilled」、副标题「选择风格来搭配组件和图标…」、主按钮「应用风格」

**验证**：`node --check` EXIT=0；探针 —— 启动即 `wall=6 云白`（浅色）、body `rgb(238,242,248)`、经典令牌 label/search/mask 均为深色与白色遮罩；切「暗黑」→ `wall=2 海岸`、mask `#060a10`、label `#ffffff`；切回经典恢复浅色；两套页面溢出扫描全空、`errs=[]`。截图核对：首页为浅色（深字搜索框、深色名称标签与翻页圆点、白底卡片），欢迎弹窗四张预览卡「经典/光感」为浅色、「暗黑/黑紫」为深色。

## Dock 视觉优化 + 全局透明度（本轮第五批）

用户反馈「底部原型太丑了，有没有优化空间」，并要求「增加全局透明度的设计」。

**Dock 为什么丑（探针查出的实据）**：8 个应用图标走的是「白底 + 品牌色首字」占位，其中 **音乐 / 影视 / 头像 / 百度网盘 四个在素材表 `B` 里没有条目 → 全部退化成同一个石板灰 `#64748B` 白字**；加上 4 个功能按钮又分别是深灰 / 粉紫 / 青 / 深蓝四种互不相关的跳色，整条栏既发灰又杂乱。

**改法**：
- 应用图标改为**品牌色实底 + 白色首字**（`tileHTML(..., forceSolid)`，Dock 专用），并补齐 音乐 `#EC4899` / 影视 `#7C3AED` / 头像 `#E08A4A` / 百度网盘 `#3385FF`
- 4 个功能按钮统一为扁平色 `#3b82f6` / `#a855f7` / `#0ea5e9` / `#64748b`，与图标同一圆角（20px）与同一投影
- 栏体加 `inset 0 1px 0 rgba(255,255,255,.45)` 顶部高光（浅色壁纸下也能看出悬浮栏）、分隔线由写死的白色改为 `--label-color` 的 28%、默认 `--dock-alpha` 由 .18 提到 .26
- 顺带清掉 `renderDock` 里写死的行内背景（改由 CSS 从令牌算）

**全局透明度设计**（只作用于「面」的背景，文字与图标始终不透明）：
- `--g-alpha`（0.2–1，默认 1）总开关；按令牌取色的面统一写成 `color-mix(in srgb, <令牌> calc(var(--g-alpha) * 100%), transparent)`——卡片、抽屉、弹窗、右键菜单与二级菜单、模式胶囊与气泡、搜索建议面板全覆盖；已是 `rgba()` 的令牌同样成立（等于继续乘算 alpha）

- `--glass-blur`：全局 100% 时为 `0px`，一旦低于 100% 自动变 `18px`，给抽屉 / 弹窗 / 右键菜单 / 建议面板加毛玻璃（卡片与胶囊不加，沿用 UiTab 的「薄透」观感，也避免 37 张卡片各建一层合成层）
- UI 落在「个性化 → 透明度」新分组：全局透明度 / 搜索框透明度 / Dock栏透明度 三个滑杆 + 一句说明；原搜索框与 Dock 分组里的重复滑杆已删除

## 两个维度：透明度（全局）+ 玻璃质感（分功能）（本轮第七批）

用户要求：「都是纯色的，加点透明度 玻璃质感；文档写明这 2 个可调——透明度全局可调、玻璃质感分功能可调」。

**问题**：界面里所有面（卡片 / 图标容器 / Dock / 搜索框 / 面板 / 菜单）都是**不透明纯色**；旧的「全局透明度」只缩放 alpha，且 `--glass-blur` 是单一全局值（100% 时直接为 0），所以看不出玻璃；且「全局透明度 / 栏透明度 / 搜索框透明度」三个滑杆语义重叠。

**改法**：
- 模型收敛为两个互不干涉的维度：**透明度 = 全局一个**（`--g-alpha`，缩放所有面的 alpha）；**玻璃质感 = 分功能 6 条**（卡片 / 图标容器 / Dock 栏 / 搜索框 / 面板与弹窗 / 菜单与浮层），每条 `alpha = 1 − 0.55×值`、`blur = 26px×值`，**0% 即回到不透明纯色平面**。默认：卡片 60 / 图标容器 35 / Dock 70 / 搜索框 45 / 面板 65 / 菜单 65
- 实现：`state.glass = {card,tile,dock,search,panel,menu}` → `applySkin` 写入 `--ga-<面>` 与 `--blur-<面>`；面写成 `color-mix(in srgb,<令牌> calc(var(--g-alpha) * var(--ga-<面>) * 100%),transparent)` + `backdrop-filter:blur(var(--blur-<面>))`；滑杆用 `data-inp="glass:card"` 形式，输入处理器新增 `glass:` 分支
- 删掉三个旧旋钮（`--glass-blur` / `--search-alpha` / `--dock-alpha` 与 state 里的 `searchOpacity` / `dockAlpha`），Dock 与搜索框的旧滑杆并入玻璃质感
- **清理会把玻璃盖回不透明的重复底色**：`#stage` 的第二层 `background`、`.w-group` / `.w-news` / `.w-folder` / `.wp-prev` 各自的 `--card-bg` 底
- **给壁纸加极细斜纹**（`repeating-linear-gradient(135deg,rgba(122,136,160,.075) 0 1px,transparent 1px 8px)`，`background-size:cover,auto`）：纯色渐变壁纸下毛玻璃不可见，斜纹是玻璃的参照物

**验证**：`node --check` EXIT=0；探针 —— 默认各面均为「半透 + 模糊」（卡片 `.67`+`15.6px`、图标容器 `.81`+`9.1px`、Dock `.62`+`18.2px`、搜索框 `.75`+`11.7px`、抽屉与右键菜单 `.64`+`16.9px`、胶囊 `.35`）；全局透明度调 50% → 所有 alpha 减半而**模糊不变**（两维度独立）；把「卡片」玻璃单独调 0 → 卡片 `rgb(255,255,255)` + `blur(0px)` 且图标容器保持 `.81`（分功能隔离）；抽屉内滑杆 11 条、`glass:` 键 6 条齐全；溢出扫描全空、`errs=[]`。截图：浅色壁纸下斜纹隐约可见、暗黑皮肤 3 倍放大可见瓦片透出背后并柔化。
