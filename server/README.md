# Thrilled 云端存储参考服务端

零依赖 Node 单文件，为客户端「云端同步」提供文档存取端点。

## 端点

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/thrilled/doc` | 拉取整份文档；无数据返回 404 |
| PUT | `/thrilled/doc` | 保存整份文档（覆盖式） |
| GET | `/health` | 健康检查 |

## 运行

```bash
TOKEN=你的访问令牌 PORT=8787 node server/server.mjs
```

- `TOKEN`：访问令牌；未设置时不鉴权（仅限本机 / 可信内网使用）
- `PORT`：监听端口，默认 8787
- `DATA_DIR`：数据目录，默认 `server/data/`（已加入 .gitignore，不会入库）

数据以整份 JSON 文档（`doc.json`）原子写盘（临时文件 + rename）。

## 客户端接入

1. 启动本服务端（任意 Node 主机 / 内网机器均可）
2. Thrilled → 设置抽屉 → 「云端同步」：填入 `http://<主机>:8787` 与令牌 → 保存配置
3. 「上传到云端」首推本地数据；此后改动自动上传
4. 其他设备 / 浏览器：填**同一份配置** → 「从云端恢复」即可一键还原（以云端最新版本为准）

## 安全约定

- 服务器地址与令牌只保存在各设备的浏览器本地存储，**不进入代码仓库**
- 仓库内不含任何真实云端配置、令牌或用户数据
- 公网部署请务必设置 `TOKEN`，并置于 HTTPS 反向代理之后
